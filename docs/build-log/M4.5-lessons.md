# M4.5: Programme page + lesson player with progress

## Goal
A lesson list per programme, and a lesson page that remembers your position and lets you mark the lesson complete. Progress writes are access-checked on the server.

## Files you may touch
`src/app/dashboard/programmes/[slug]/page.tsx`, `src/app/dashboard/lessons/[id]/page.tsx`, `src/app/dashboard/lessons/[id]/player.tsx`, `src/app/dashboard/lessons/[id]/actions.ts`, `src/components/dashboard/*`, `src/lib/progress.ts`.

## Steps
1. `src/lib/progress.ts`: `saveProgress(db, userId, lessonId, { positionSec, completed }, now)`:
   - **First** `canWatchLesson`; if not allowed → throw. (A locked user must not be able to write progress by calling the action directly.)
   - Upsert `lesson_progress` on (user_id, lesson_id). `completed: true` sets `completed_at` once and never clears it. Clamp `positionSec` to 0…duration.
2. `actions.ts`: a server action `saveProgressAction(lessonId, positionSec, completed)` that validates with Zod, uses `auth()` for the userId (**never** takes userId from the client), and calls `saveProgress`.
3. Programme page: header (EN + Arabic title, progress bar), then the lesson list: position, EN title, Arabic title (RTL), duration, and a state icon (✓ completed, ▶ in progress, 🔒 locked, "Preview" badge). Locked rows link to the lesson page, which shows the locked card. Unknown slug → `notFound()`.
4. Lesson page (extend M4.3, keeping the gating exactly as is):
   - `player.tsx` (client): `<video>` starts at `last_position_sec`. It saves progress every 15 s while playing, on pause, and on `visibilitychange` → hidden. When `ended` fires, or the student clicks **Mark complete**, it saves with `completed: true` and shows a toast.
   - Below the player: "Previous / Next lesson" navigation within the programme.
