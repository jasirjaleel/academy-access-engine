# M1.2: Database connection + full schema

## Before you start (Jasir)
Create a Supabase project (region: closest to the UAE, e.g. Mumbai or Frankfurt). From **Connect**, copy:
- **Transaction pooler** URL (port 6543) → `DATABASE_URL` in `.env.local`
- **Session pooler / direct** URL (port 5432) → `DATABASE_URL_DIRECT`

## Goal
Drizzle connected to Supabase, every table from `docs/ARCHITECTURE.md` defined in `src/db/schema.ts`, and the first migration applied.

## Files you may touch
`package.json`, `drizzle.config.ts`, `src/db/schema.ts`, `src/db/index.ts`, `drizzle/**` (generated only), `src/lib/env.ts` (add `DATABASE_URL_DIRECT` as optional).

## Steps
1. `npm install drizzle-orm postgres` and `npm install -D drizzle-kit dotenv`.
2. `drizzle.config.ts`: load `.env.local` with dotenv, `dialect: "postgresql"`, `schema: "./src/db/schema.ts"`, `out: "./drizzle"`, `dbCredentials.url = process.env.DATABASE_URL_DIRECT`.
3. `src/db/index.ts`: `postgres(env.DATABASE_URL, { prepare: false })` (required for the Supabase transaction pooler), wrapped with `drizzle(client, { schema })`. Cache the client on `globalThis` in development to avoid too many connections during hot reload. Export `db` and the type `DB = typeof db`.
4. `src/db/schema.ts`: define **exactly** the tables, columns, enums, foreign keys and unique constraints from ARCHITECTURE.md → "Tables". Rules:
   - All timestamps: `timestamp(..., { withTimezone: true })`; `created_at`/`updated_at` default `now()`.
   - Enums with `pgEnum`: `entitlement_source`, `entitlement_status`, `outbound_status`.
   - Foreign keys to `users.id` use `onDelete: "cascade"` for `lesson_progress` and `cancellation_feedback`, and `restrict` for everything else.
   - Add indexes: `entitlements(user_id)`, `outbound_events(status, next_attempt_at)`, `invoices(user_id)`.
   - Export inferred types (`typeof users.$inferSelect` etc.) for each table.
5. `npm run db:generate`, then `npm run db:migrate`.

## ✅ Check (Jasir runs)
- In Supabase → Table Editor, all 10 tables exist: users, programmes, lessons, subscriptions, entitlements, invoices, lesson_progress, cancellation_feedback, processed_events, outbound_events. (Drizzle keeps its own migrations table in a separate `drizzle` schema.)
- Open `entitlements`: the unique constraint on (user_id, programme_id, source, source_ref) is there.
- `npm run typecheck` passes.
