# M2.3: Admin guard

## Goal
`/admin` only opens for users with Clerk `publicMetadata.role === "admin"`; everyone else gets a 404 (we don't reveal that the page exists).

## Files you may touch
`src/lib/auth.ts`, `src/app/admin/layout.tsx`, `src/app/admin/page.tsx`.

## Steps
1. `src/lib/auth.ts`: `requireAdmin()`, which calls `currentUser()` and, if there is no user or `publicMetadata.role !== "admin"`, calls `notFound()`. Returns the user.
2. `admin/layout.tsx`: a server component that calls `await requireAdmin()` and renders a simple sidebar layout (links: Overview, Payments, Webhooks, Outbox; the pages come in M9).
3. `admin/page.tsx`: placeholder "Admin overview".

- Clerk dashboard → Users → you → Metadata → public: `{"role":"admin"}` → reload → admin opens.
