# M2.4: Apply the design system (theme, fonts, background, nav, hero)

## Goal
The whole app uses the look from `docs/DESIGN.md`: midnight navy, amber accents, Inter, glassy cards. After this, every later UI task just reuses these tokens and recipes.

## Files you may touch
`package.json`, `src/app/globals.css`, `src/app/layout.tsx`, `src/components/background-pattern.tsx`, `src/components/site-header.tsx`, `src/app/(marketing)/page.tsx`, `src/app/sign-in/[[...sign-in]]/page.tsx`, `src/app/sign-up/[[...sign-up]]/page.tsx`, `src/components/ui/button.tsx` (variants only).

## Steps
1. **Fonts** (`layout.tsx`): remove Geist and Geist Mono. Add `Inter` (variable `--font-inter`) and `Noto_Naskh_Arabic` (subsets `["arabic"]`, weights 400/600/700, variable `--font-naskh`) from `next/font/google`. Put both variables plus the `dark` class on `<html>`.
2. **Tokens** (`globals.css`): replace the colour variables with **exactly** the tokens and the shadcn mapping from DESIGN.md → "Tokens". Delete the light theme block, so there's one dark theme only. Make sure `--font-sans` points to `var(--font-inter)` (not to itself). Add a `.font-arabic` utility via `--font-arabic`. `body` gets `bg-midnight text-slate-200`.
3. **Button variants** (`button.tsx`): set the `default` variant to the DESIGN.md primary button recipe and `secondary` to the secondary recipe. Leave the other variants alone.
4. **Background** (`background-pattern.tsx`): a server component that renders a fixed, full-screen `<svg>` (`-z-10 pointer-events-none`) with a `<pattern>` of 56×56 px. In each tile: an 8-point star made of two 24×24 squares centred on (28,28), one of them rotated 45°, `fill="none" stroke="white" strokeWidth="1"`. The whole SVG at `opacity-[0.04]`. Add two blurred glow circles per DESIGN.md → Layout. Render it once in `layout.tsx`.
5. **Header** (`site-header.tsx`): the DESIGN.md **top nav** recipe. On the left, a text logo: "Demo Academy" in white with a small amber dot before it. In the centre, a pill with Pricing · Dashboard. On the right, the Clerk buttons (Sign in as a dark pill with an amber ring, or `<UserButton />`). Under 640 px, show only the logo + a menu button that opens the links (simple state, no new deps).
6. **Landing hero** (`(marketing)/page.tsx`): eyebrow "Demo Academy"; h1 "Islamic learning, *beautifully delivered*" (accent gradient on the last two words); subtitle "Learn Arabic and the Islamic sciences, at your pace."; a primary button "View plans" + arrow (→ `/pricing`) and a secondary button "Student login" (→ `/dashboard`); a small caption "From $15/month • Cancel anytime". Below that, one **highlight card**: gift icon, eyebrow "Free with any programme", title "Foundations of Knowledge", one-line description.
7. **Clerk pages:** `npm install @clerk/themes`; on `<SignIn />` and `<SignUp />` pass the `appearance` from DESIGN.md.
8. Nothing with another organisation's name, logo or images (AGENTS.md rule 14).
