# M3.1: Stripe products, prices and coupon (setup script)

## Before you start (Jasir)
Create a Stripe account and stay in **Test mode**. Copy the test secret key (`sk_test_…`) and publishable key (`pk_test_…`) into `.env.local`. Install the Stripe CLI (`brew install stripe/stripe-cli/stripe`) and run `stripe login`.

## Goal
One re-runnable script creates the catalogue in Stripe test mode and prints the price IDs. `lib/stripe.ts` maps prices ↔ product keys.

## Files you may touch
`package.json`, `scripts/stripe-setup.ts`, `src/lib/stripe.ts`, `src/lib/env.ts`.

## Steps
1. `npm install stripe`.
2. `scripts/stripe-setup.ts` (run with `npx tsx scripts/stripe-setup.ts`, loads `.env.local` via dotenv; refuses to run if the key doesn't start with `sk_test_`):
   - For each product below, find the price by `lookup_key` (`stripe.prices.list({ lookup_keys: [...] })`). If it exists, reuse it; otherwise create the product + price with that `lookup_key`. **Running it twice must not create duplicates.**
     | lookup_key | product name | amount | type |
     |---|---|---|---|
     | `arabic_monthly` | Arabic Programme (monthly) | 2400 USD | recurring, month |
     | `precision_monthly` | Precision in Knowledge (monthly) | 2400 USD | recurring, month |
     | `lifetime` | Lifetime Access | 49900 USD | one-time |
   - Coupon id `REGION40`, 40% off, `duration: "once"` (create only if `coupons.retrieve` 404s), plus a promotion code `REGION40` for it (only if none is active with that code).
   - Print the lines to paste into `.env.local`: `STRIPE_PRICE_ARABIC_MONTHLY=price_…` etc.
3. `src/lib/stripe.ts` (`import "server-only"`):
   - `export const stripe = new Stripe(env.STRIPE_SECRET_KEY)` (use the SDK's default API version).
   - `PRODUCTS`: a typed map `product_key → { priceId, mode: "subscription" | "payment", programmes: ("arabic"|"precision")[] }`. Arabic → `["arabic"]`, Precision → `["precision"]`, lifetime → `["arabic","precision"]`.
   - `productKeyFromPriceId(priceId)`: reverse lookup; returns `null` if unknown.
4. `env.ts`: make `STRIPE_SECRET_KEY`, `NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY` and the 3 price vars **required**. Keep the `sk_test_` guard.

