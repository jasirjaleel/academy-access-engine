# M1.1: Scaffold the app

## Goal
A running Next.js + TypeScript + Tailwind + shadcn/ui app in this repo, with a validated env module and the npm scripts from AGENTS.md.

## Files you may touch
Everything that `create-next-app` and `shadcn init` generate, plus `package.json`, `.gitignore`, `.env.example`, `src/lib/env.ts`, `src/app/(marketing)/page.tsx`, `src/app/layout.tsx`.
**Do not modify** `AGENTS.md`, `MILESTONES.md`, `docs/`, `tasks/`.

## Steps
1. This folder is not empty, so scaffold in a temp folder and move the files in:
   ```
   npx create-next-app@latest ../aae-scaffold --ts --tailwind --eslint --app --src-dir --import-alias "@/*" --use-npm --yes
   ```
   Copy everything from `../aae-scaffold` (including dotfiles, excluding `.git` and `node_modules`) into this repo **without overwriting** the existing files listed above. Delete `../aae-scaffold`, then run `npm install`.
2. `npx shadcn@latest init` (defaults, neutral base colour), then `npx shadcn@latest add button card badge progress separator skeleton sonner`.
3. `npm install zod` and `npm install -D tsx`.
4. Add these scripts to `package.json`:
   `"typecheck": "tsc --noEmit"`, `"test": "vitest run"` (Vitest is installed later in M4.6, so the script may fail until then), `"db:generate": "drizzle-kit generate"`, `"db:migrate": "drizzle-kit migrate"`, `"db:seed": "tsx src/db/seed.ts"`.
5. `.gitignore` must contain `.env*` **and** `!.env.example`.
6. Create `.env.example` with **every** variable listed in `docs/ARCHITECTURE.md` → "Env vars", with empty values and the comments kept.
7. Create `src/lib/env.ts`:
   - Zod schema for server env. For now, **required:** `DATABASE_URL`, `NEXT_PUBLIC_APP_URL`. **Optional for now** (they get required in later milestones): all the others.
   - Add a refinement: if `STRIPE_SECRET_KEY` is set, it must start with `sk_test_`, otherwise throw `"Live Stripe keys are not allowed in this project"`.
   - Export `env` (parsed once). Mark the file server-only with `import "server-only"` (`npm install server-only`).
8. Move the home page into the `(marketing)` route group: `src/app/(marketing)/page.tsx`. Replace the boilerplate with a simple hero: title "Demo Academy", subtitle "Learn Arabic and the Islamic sciences, at your pace.", and two shadcn Buttons: "View plans" (→ `/pricing`, page doesn't exist yet, that's fine) and "Student login" (→ `/dashboard`).
9. In `layout.tsx`, set the metadata title to "Demo Academy", keep the Geist font, and add a `<Toaster />` from sonner.
