# M3.2: Pricing page + checkout

## Goal
A logged-in student picks a plan, pays on Stripe Checkout, and returns. **No access is granted here.** Access only comes from the webhook (M4).

## Files you may touch
`src/app/(marketing)/pricing/page.tsx`, `src/components/pricing-card.tsx`, `src/app/api/checkout/route.ts`, `src/lib/customers.ts`.

## Steps
1. `src/lib/customers.ts`: `getOrCreateStripeCustomer(db, user)`. If `users.stripe_customer_id` is set, return it. Otherwise call `stripe.customers.create({ email, name, metadata: { userId } }, { idempotencyKey: "customer-create-" + user.id })` (so a double click can't create two customers), save the ID, and return it.
2. `POST /api/checkout`:
   - Require a signed-in user (`auth()`), or return 401. Validate the body with Zod: `{ productKey: "arabic_monthly" | "precision_monthly" | "lifetime" }`.
   - `getOrCreateUser(db)` (from M2.2) → `getOrCreateStripeCustomer`.
   - **Block double purchases (409 with a friendly message):** if the user already has an `active`/`grace` entitlement with source `lifetime`, or (for a monthly plan) an active/grace `subscription` entitlement for that programme.
   - Create the Checkout Session:
     - `mode` from `PRODUCTS[productKey].mode`, `line_items: [{ price, quantity: 1 }]`, `customer`, `client_reference_id: userId`, `allow_promotion_codes: true`
     - `metadata: { userId, productKey }`
     - subscription mode: `subscription_data: { metadata: { userId, productKey } }`
     - payment mode: `payment_intent_data: { metadata: { userId, productKey } }`
     - `success_url: {APP_URL}/dashboard/billing/success?session_id={CHECKOUT_SESSION_ID}`, `cancel_url: {APP_URL}/pricing?canceled=1`
   - Return `{ url }`.
3. Pricing page: 3 shadcn cards: **Arabic**, $24/month; **Precision in Knowledge**, $24/month; **Lifetime**, $499 one-time, marked "Best value", "Own both programmes forever". Each card lists "Includes *Foundations of Knowledge* free". The button is a client component: POST → `window.location.href = url`. Show a loading state and toast errors (sonner). Signed-out users clicking → `/sign-in?redirect_url=/pricing`. A small line under the cards: "Regional pricing available: use code REGION40 at checkout."
4. If `?canceled=1`, show a neutral toast "Checkout canceled. You haven't been charged."
